StudyVault is a **full-stack web application** designed to help students easily access and organize study resources in one place.

Students often struggle to find **reliable study materials, previous year question papers, and curated learning resources** scattered across different platforms.
StudyVault solves this problem by bringing everything together into a **single, structured platform**.

# ✨ Features

* 📖 Browse study materials by **subject or topic**
* 📝 Access **previous year question papers**
* 🎥 Discover curated **learning resources and tutorials**
* 🎨 Clean and responsive **user interface**
* 🔗 **REST API based backend** for managing study resources
* 🏗️ Scalable **full-stack architecture**

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/StudyVault.git
cd StudyVault
```

---

## 2️⃣ Run Backend (Spring Boot)

Navigate to the backend folder:

```bash
cd backend
```

Run the Spring Boot application:

```bash
mvn spring-boot:run
```

Backend will start on:

```
http://localhost:8080
```

---

## 3️⃣ Run Frontend (React)

Navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Frontend will start on:

```
http://localhost:5173
```
